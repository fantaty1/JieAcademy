## 1. 这个系统是做什么的？

### 简单理解

想象一下这个场景：

1. 你在 TradingView（一个看股票/加密货币图表的网站）上设置了一个策略
2. 策略说："当比特币价格跌破某个支撑位时，自动买入"
3. 以前你需要手动去交易所下单
4. 现在有了这个系统，TradingView会自动通知它，它会帮你自动在币安交易所下单

### 工作流程图

```
TradingView（你的策略）
       ↓ 发送信号（Webhook）
你的服务器（运行本系统）
       ↓ 自动下单
币安交易所（完成交易）
```

### 通俗比喻

- **TradingView** = 你的投资顾问，告诉你"该买"或"该卖"
- **本系统** = 你的交易员，收到指令后自动去交易所下单
- **币安** = 股票交易所，实际执行买卖的地方

## 2. 开始前你需要准备什么

### 必须有的东西

| 序号 | 准备事项 | 说明 |
|------|----------|------|
| 1 | 币安账号 | 注册地址：https://www.binance.com/zh-CN |
| 2 | TradingView账号 | 注册地址：https://www.tradingview.com/ （免费即可） |
| 3 | 一台云服务器 | 推荐：腾讯云、阿里云、AWS（海外服务器最佳） |
| 4 | 基本的电脑操作能力 | 会复制粘贴命令就行 |

### 推荐的服务器配置

- **操作系统**：Ubuntu 20.04 或 22.04（新手推荐）
- **配置**：1核CPU、1GB内存、20GB硬盘（最低配置）
- **价格**：约 30-50 元/月
- **重要**：必须是**海外服务器**（如新加坡、美国），国内服务器无法访问币安API

### 为什么要海外服务器？

币安在中国大陆无法直接访问，所以你的服务器需要在海外才能正常连接币安API。

## 4. 第二步：创建API密钥

> **API密钥是什么？**
> 
> 简单说，API密钥就是让本系统能够访问你币安账户的"钥匙"。就像你给交易员一张银行卡和密码，让他帮你操作一样。

### 4.1 进入API管理页面

1. 登录币安
2. 把鼠标移到右上角你的头像上
3. 点击"API管理"
4. 或者直接访问：https://www.binance.com/zh-CN/my/settings/api-management

### 4.2 创建新的API密钥

1. 点击"创建API"按钮
2. 给API起个名字，比如：`我的自动交易系统`
3. 点击"创建"

### 4.3 验证身份

系统会要求你进行安全验证：
- 邮箱验证码
- 手机验证码
- Google验证码（如果开启了双重认证）

### 4.4 保存API密钥

创建成功后，你会看到两个东西：
- **API Key**：类似 `abc123def456...`（一串字母数字）
- **Secret Key**：类似 `xyz789uvw012...`（另一串字母数字）

> **⚠️ 超级重要：**
> 
> 1. **Secret Key只显示一次！** 一定要立即复制保存到安全的地方
> 2. 如果没保存，只能删除重新创建
> 3. **绝对不要分享给任何人！**

### 4.5 设置API权限（非常重要！）

在API管理页面，找到你刚创建的API，点击"编辑"：

**必须开启的权限：**
- ✅ 启用现货

**绝对不能开启的权限：**
- ❌ 启用提现（绝对不要开！开了别人可以转走你的钱！）

### 4.6 设置IP白名单（强烈推荐）

在API编辑页面，找到"IP访问限制"：

1. 选择"限制访问"
2. 输入你的服务器公网IP地址
3. 点击"确认"

> **如何查看服务器公网IP？**
> 
> 在服务器上执行命令：`curl ifconfig.me`
> 
> 或者在百度搜索"我的IP"

### 4.7 获取测试网API Key（推荐先用这个练习）

在正式使用前，强烈建议先用测试网练习：

1. 访问：https://testnet.binance.vision/
2. 用GitHub账号登录
3. 点击"API Key"标签
4. 点击"Generate HMAC_SHA256 Key"
5. 保存生成的API Key和Secret Key

测试网使用的是虚拟资金，不会损失真钱，非常适合新手练习！

## 5. 第三步：下载和配置系统

### 5.1 连接到你的服务器

**Windows用户：**
1. 下载并安装 PuTTY：https://www.putty.org/
2. 打开PuTTY
3. 输入服务器IP地址
4. 点击"Open"
5. 输入用户名（通常是 `root`）和密码

**Mac用户：**
1. 打开"终端"应用
2. 输入：`ssh root@你的服务器IP`
3. 输入密码

### 5.2 安装Python

连接到服务器后，依次执行以下命令：

```bash
# 更新系统
sudo apt update

# 安装Python和pip
sudo apt install -y python3 python3-pip python3-venv

# 检查Python版本（应该是3.8以上）
python3 --version
```

### 5.3 下载项目代码

```bash
# 进入opt目录
cd /opt

# 下载代码（如果你有git仓库）
git clone https://github.com/你的用户名/你的仓库名.git tv-trader

# 或者手动创建项目目录
mkdir tv-trader
cd tv-trader
```

### 5.4 创建配置文件

```bash
# 创建配置文件
nano .env
```

在打开的编辑器中，粘贴以下内容（**替换为你自己的信息**）：

```ini
# ============== 币安API配置 ==============
# 把下面的"你的API_KEY"和"你的API_SECRET"替换为你自己的
BINANCE_API_KEY=你的API_KEY
BINANCE_API_SECRET=你的API_SECRET

# 是否使用测试网
# 首次使用请设置为 True（测试网）
# 确认无误后改为 False（主网，使用真钱）
USE_TESTNET=True

# ============== Webhook安全配置 ==============
# 这是一个密码，TradingView发送信号时需要带上这个密码
# 请改成一个复杂的字符串，比如：MySecretKey2024!@#
WEBHOOK_SECRET=改成你自己的密码

# ============== 风控参数配置 ==============

# 全局交易开关
# True = 开启交易
# False = 停止所有交易（紧急情况下使用）
TRADING_ENABLED=True

# 单次下单最大资金比例
# 0.1 表示每次交易最多使用账户总资金的10%
# 建议新手设置为 0.05（5%）或更低
MAX_ORDER_RATIO=0.05

# 重复信号过滤时间（秒）
# 同一个信号在60秒内只执行一次
DUPLICATE_SIGNAL_WINDOW=60

# 每日最大交易次数
# 防止策略出错导致疯狂交易
MAX_DAILY_TRADES=20

# ============== 服务器配置 ==============
SERVER_HOST=0.0.0.0
SERVER_PORT=8080
```

编辑完成后：
1. 按 `Ctrl + X` 退出
2. 按 `Y` 确认保存
3. 按 `Enter` 确认文件名

### 5.5 安装依赖

```bash
# 创建虚拟环境
python3 -m venv venv

# 激活虚拟环境
source venv/bin/activate

# 安装依赖包
pip install -r requirements.txt
```

### 5.6 测试启动

```bash
# 启动系统
python main.py
```

如果看到类似以下输出，说明启动成功：

```
============================================================
  TradingView-Binance 自动量化交易系统
============================================================
```

按 `Ctrl + C` 可以停止程序。

## 7. 第五步：配置TradingView

### 7.1 创建TradingView账号

1. 访问 https://www.tradingview.com/
2. 注册账号（免费即可）

### 7.2 找到一个策略

TradingView上有很多公开的策略，你可以：

1. 在图表页面点击"指标"（Indicators）
2. 选择"社区脚本"
3. 搜索你感兴趣的策略（比如搜索 "RSI Strategy"）
4. 点击添加到图表

### 7.3 创建警报

1. 在图表上点击"警报"按钮（闹钟图标）
2. 或者按快捷键 `Alt + A`

### 7.4 配置警报设置

**条件设置：**
- 选择你添加的策略
- 选择触发条件（如"买入信号"）

**警报动作：**
1. 选择"Webhook URL"
2. 填入你的服务器地址：`http://你的服务器公网IP:8080/webhook`

**消息内容：**

在"消息"框中填入以下内容（用于买入信号）：

```json
{
    "secret": "你设置的WEBHOOK_SECRET",
    "symbol": "{{ticker}}",
    "side": "BUY",
    "quantity": 0.001,
    "order_type": "MARKET",
    "timestamp": "{{timenow}}"
}
```

**重要说明：**
- `{{ticker}}` 会自动替换为当前交易对（如BTCUSDT）
- `{{timenow}}` 会自动替换为当前时间
- `quantity` 需要你自己设置交易数量
- `secret` 必须和你服务器上设置的一致

### 7.5 创建卖出信号警报

重复上面的步骤，创建另一个警报：

- 条件选择"卖出信号"
- 消息中的 `"side"` 改为 `"SELL"`

```json
{
    "secret": "你设置的WEBHOOK_SECRET",
    "symbol": "{{ticker}}",
    "side": "SELL",
    "quantity": 0.001,
    "order_type": "MARKET",
    "timestamp": "{{timenow}}"
}
```

### 7.6 测试TradingView信号

1. 确保你的服务器系统正在运行
2. 在TradingView中手动触发一个测试信号
3. 查看服务器日志，确认信号已收到

## 8. 第六步：部署到云服务器

### 8.1 为什么要部署到云服务器？

- 你的电脑关机后，系统就停止了
- 云服务器24小时运行，不会错过任何信号
- 更稳定、更安全

### 8.2 使用systemd配置自动启动

```bash
# 复制服务配置文件
sudo cp /opt/tv-trader/systemd/tv-trader.service /etc/systemd/system/

# 编辑配置文件（如果需要）
sudo nano /etc/systemd/system/tv-trader.service
```

确保配置文件中的路径正确：

```ini
[Unit]
Description=TradingView-Binance 自动量化交易系统
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/opt/tv-trader
Environment="PATH=/opt/tv-trader/venv/bin"
ExecStart=/opt/tv-trader/venv/bin/python main.py
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

### 8.3 启动服务

```bash
# 重新加载systemd配置
sudo systemctl daemon-reload

# 启动服务
sudo systemctl start tv-trader

# 设置开机自启
sudo systemctl enable tv-trader

# 查看服务状态
sudo systemctl status tv-trader
```

### 8.4 常用管理命令

```bash
# 启动服务
sudo systemctl start tv-trader

# 停止服务
sudo systemctl stop tv-trader

# 重启服务
sudo systemctl restart tv-trader

# 查看状态
sudo systemctl status tv-trader

# 查看日志
sudo journalctl -u tv-trader -f

# 查看实时日志
tail -f /opt/tv-trader/logs/tv_trader.log
```

### 8.5 配置防火墙

如果使用的是云服务器，需要开放8080端口：

**腾讯云/阿里云：**
1. 登录云服务商控制台
2. 找到你的服务器实例
3. 进入"安全组"设置
4. 添加入站规则：端口8080，协议TCP，来源0.0.0.0/0

**Ubuntu自带防火墙：**
```bash
sudo ufw allow 8080/tcp
sudo ufw reload
```

## 9. 常见问题解答

### Q1: 信号发送了但没有执行交易？

**检查清单：**

1. **检查服务是否运行**
   ```bash
   sudo systemctl status tv-trader
   ```

2. **检查日志**
   ```bash
   tail -f /opt/tv-trader/logs/tv_trader.log
   ```

3. **检查Webhook密钥是否一致**
   - TradingView中的 `secret` 必须和服务器 `.env` 中的 `WEBHOOK_SECRET` 完全一致

4. **检查交易开关**
   - `.env` 中的 `TRADING_ENABLED` 必须是 `True`

5. **检查是否触发了风控**
   - 可能是重复信号被过滤了
   - 可能是达到每日交易次数限制

6. **检查网络**
   - 确保服务器能访问币安API
   - 执行 `curl https://api.binance.com/api/v3/ping` 测试

### Q2: 如何停止自动交易？

**方法一：修改配置文件**
```bash
nano /opt/tv-trader/.env
# 将 TRADING_ENABLED=True 改为 TRADING_ENABLED=False
sudo systemctl restart tv-trader
```

**方法二：直接停止服务**
```bash
sudo systemctl stop tv-trader
```

### Q3: 如何查看交易记录？

```bash
# 查看所有日志
cat /opt/tv-trader/logs/tv_trader.log

# 只看交易相关的日志
cat /opt/tv-trader/logs/trades.log

# 实时查看日志
tail -f /opt/tv-trader/logs/tv_trader.log
```

### Q4: 服务器重启后系统会自动运行吗？

如果配置了systemd并执行了 `sudo systemctl enable tv-trader`，系统会自动启动。

如果没有，手动启动：
```bash
sudo systemctl start tv-trader
```

### Q5: 可以同时交易多个币种吗？

可以！只要TradingView发送不同的交易对信号，系统会自动处理。

### Q6: 交易数量怎么设置？

在TradingView的警报消息中修改 `quantity` 字段：
- BTC数量较小，如 `0.001`
- ETH数量适中，如 `0.01`
- 小币种数量较大，如 `100`

具体数量取决于你想要投入多少资金。

### Q7: 如何更新系统代码？

```bash
cd /opt/tv-trader
sudo systemctl stop tv-trader

# 如果使用git
git pull

# 重新安装依赖（如果有更新）
source venv/bin/activate
pip install -r requirements.txt

sudo systemctl start tv-trader
```

## 10. 安全注意事项

### ⚠️ 必须遵守的安全规则

1. **API权限设置**
   - 只开启"现货交易"权限
   - 绝对不要开启"提现"权限
   - 开启提现权限 = 把钱送给别人

2. **IP白名单**
   - 在币安后台设置API的IP白名单
   - 只允许你的服务器IP访问
   - 这样即使密钥泄露，别人也无法使用

3. **资金控制**
   - 不要在账户中放太多资金
   - 设置合理的单次交易比例（建议5%以下）
   - 设置每日最大交易次数

4. **定期检查**
   - 每天查看一次交易日志
   - 每周检查一次账户余额
   - 发现异常立即停止交易

5. **密钥安全**
   - 不要将API密钥告诉任何人
   - 不要将 `.env` 文件上传到公开的地方
   - 定期更换API密钥

### 🚨 紧急情况处理

**如果发现异常交易：**

1. 立即停止服务：
   ```bash
   sudo systemctl stop tv-trader
   ```

2. 在币安后台删除或禁用API密钥

3. 检查交易日志，找出问题原因

4. 联系币安客服（如果需要）
