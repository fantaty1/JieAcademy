# 劫招社 — 永劫无间教学资料库 开发文档

---

## 一、项目概述

**项目名称**：劫招社  
**项目定位**：永劫无间全武器全英雄教学资料库，纯攻略文档站，非 UGC 平台  
**核心功能**：文档攻略阅读 + 外部视频链接跳转（抖音）  
**内容来源**：管理员维护，非用户投稿  

---

## 二、技术栈

| 层级 | 技术 | 版本 |
|------|------|------|
| 前端框架 | Vue 3 (Composition API) | 3.x |
| 构建工具 | Vite | 5.x |
| UI 组件库 | Element Plus | 2.x |
| 状态管理 | Pinia | 2.x |
| 路由 | Vue Router | 4.x |
| HTTP 请求 | Axios | 1.x |
| 后端框架 | Django | 4.x |
| API 框架 | Django REST Framework | 3.x |
| 认证 | JWT (djangorestframework-simplejwt) | - |
| 数据库 | MySQL | 8.0 |
| 跨域 | django-cors-headers | - |

## 四、数据库设计

### 4.1 用户表 `users`

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INT PK AUTO_INCREMENT | 主键 |
| username | VARCHAR(50) UNIQUE | 用户名 |
| email | VARCHAR(100) UNIQUE | 邮箱 |
| password | VARCHAR(128) | 密码（哈希） |
| nickname | VARCHAR(50) | 昵称 |
| avatar | VARCHAR(255) | 头像 URL |
| is_admin | BOOLEAN DEFAULT FALSE | 是否管理员 |
| created_at | DATETIME | 注册时间 |

### 4.2 教学文章表 `tutorials`

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INT PK AUTO_INCREMENT | 主键 |
| target_id | VARCHAR(50) UNIQUE | 目标ID（如 'changjian', 'jianan'，与前端硬编码的ID对应） |
| target_type | VARCHAR(20) | weapon(武器) / hero(英雄) |
| content | TEXT (Markdown) | 长文档教学笔记内容 |
| updated_at | DATETIME | 更新时间 |

### 4.3 ER 关系

```
users (管理员) 管理 tutorials
（注：武器和英雄的基础数据已在前端硬编码实现，不再需要数据库表）
```

## 五、API 接口设计

### 5.1 认证接口

| 方法 | 路径 | 说明 | 权限 |
|------|------|------|------|
| POST | `/api/auth/register/` | 注册 | 公开 |
| POST | `/api/auth/login/` | 登录，返回 JWT | 公开 |
| POST | `/api/auth/refresh/` | 刷新 Token | 公开 |
| GET | `/api/auth/profile/` | 获取当前用户信息 | 需登录 |
| PUT | `/api/auth/profile/` | 更新个人信息 | 需登录 |

### 5.2 玩家社区互动接口 (UGC)

| 方法 | 路径 | 说明 | 权限 |
|------|------|------|------|
| GET | `/api/contributions/` | 获取玩家心得/连招列表（支持按 `target_id`, `target_type`, `category` 筛选） | 公开 |
| POST | `/api/contributions/` | 发布新的连招或感悟 | 需登录 |
| GET | `/api/contributions/{id}/` | 获取单条心得详情 | 公开 |
| PUT | `/api/contributions/{id}/` | 更新心得内容 | 需登录（需为本人） |
| DELETE | `/api/contributions/{id}/` | 删除心得内容 | 需登录（需为本人） |

### 5.3 响应格式

```json
// 心得列表项
{ 
  "id": 1,
  "author_name": "热心玩家",
  "author_avatar": "http://...",
  "target_id": "changjian", 
  "target_type": "weapon",
  "category": "combo",
  "content": "长剑的基础连招是...",
  "created_at": "2023-10-01T12:00:00Z"
}
```

## 七、UI 设计规范

### 7.1 色彩体系（高级奶油浅色系）

```css
:root {
  --bg-primary: #FDFBF7; /* 暖调奶油白 */
  --bg-secondary: #FFFFFF; /* 纯白卡片 */
  --bg-tertiary: #F5F2EB; /* 稍深的米色 */
  --accent-cyan: #008B8B; /* 深墨青 - 代表英雄 */
  --accent-gold: #B8860B; /* 暗金色 - 代表近战武器 */
  --text-primary: #2C3E50; /* 深灰蓝主文本 */
  --text-secondary: #5D6D7E; /* 次要文本 */
  --glass-bg: rgba(255, 255, 255, 0.7); /* 毛玻璃背景 */
  --glass-border: rgba(255, 255, 255, 0.5); /* 毛玻璃边框 */
}
```

### 7.2 布局与视觉结构

```
┌─────────────────────────────────────────────────┐
│  NavBar: [劫招社]  近战武器 武器教学 英雄 英雄教学  │
├────────┬────────────────────────────────────────┤
│ Global │       Main Full-Screen View Area       │
│ Side   │       (Shared Background Image)        │
│ Bar    │                                        │
│ (Glass)│  ┌──────────────────────────────────┐  │
│        │  │     图鉴页：全屏 Snap 滚动视差卡片     │  │
│ · 武器  │  │     或                             │  │
│ /英雄   │  │     教学页：文档正文 + Markdown    │  │
│ 列表    │  │                                  │  │
│ 锚点    │  └──────────────────────────────────┘  │
└────────┴────────────────────────────────────────┘
```

### 7.3 核心交互与组件规范

**NavBar** — 悬浮透明，滚动时显现 `backdrop-filter: blur` 毛玻璃效果。
**Global SideBar** — 全局悬浮左侧高级导航，`rgba(255,255,255,0.05)` 极度透明玻璃质感，与右侧全屏背景无缝融合，去除冗余英文展示。
**全屏滚动视差图鉴 (List Pages)** — 隐藏系统滚动条，卡片采用大图背景+毛玻璃数据面板（包含能力值进度条展示），平滑过渡。
**高级排版** — 标题采用 `"Noto Serif SC", serif` 渐变色填充，整体展现优雅、清新的高级大片感。
